# 《不知道有多远》

> 纪念红军长征胜利 90 周年
> 在线：<https://daka-agent.github.io/longmarch/>

## 一句话

**他们出发时，不知道要走多远。**

## 这是什么

一部滚动叙事，13 屏。成品是**一个 `index.html`**，零外部依赖——没有 CDN、没有外链字体、没有框架，断网也能打开，约 87 KB。

不是游戏，不用游戏引擎。

## 三条撑起全篇的史实

1. 走了 **4 个月**，才第一次出现"长征"两个字
2. 走了 **7 个月**，才叫"万里长征"
3. 走到终点当天，才算得出"两万五千里"；连终点都是出发 **11 个月**后，在哈达铺从一张旧报纸上看到的

所以这一篇讲的不是"他们走完了两万五千里"，而是——

**他们在不知道还有多远的时候，一直在走。**

## 三条自我约束

- **不做图表、不做数据看板。** 看板天然是上帝视角：已经知道全程，才能统计全程。这一篇要的是第一人称。
  所以全篇的做法是「体感换算 + 出处可查」，不是统计。
- **不用真人照片。** 全篇只有一个真人的名字：徐特立，出发时 57 岁，是参加长征的红军中最年长的一位。
  其余都是平均数与剪影——"他们没有留下脸"。
- **不画中国地图。** 在标准地图上叠路线属"编辑"，依法须送审。改做"里程长卷"：无坐标、无国界、无版图轮廓。

## 关于数据

页面里每个数字都带出处，页脚列完整参考资料。

核验分 A / B / C / D 四级：

| 等级 | 定义 | 可否进页面 |
|---|---|---|
| A | 打开原文逐字核对 + 两个独立来源印证 | 直接用 |
| B | 打开原文逐字核对 + 单一权威来源 | 可用，标出处 |
| C | 只见过搜索摘要 | **禁止进页面** |
| D | 已弃用 | 不得使用 |

当前进页面的数据为 A / B 级。

不同来源口径不一致时（例如到达陕北人数有 7,000 余 / 6,500 / 不足 8,000 三种说法），页面只取一条并写明限定语，其余口径在页脚列出，不隐瞒。

原文带"余""约""不足"的，页面上也带——不把概数写成精确数。
